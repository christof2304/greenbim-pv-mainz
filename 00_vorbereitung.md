# Vorbereitung für den 07.12.2026 (ca. 15 Minuten)

Bitte **vor** dem Termin erledigen, damit wir in den 90 Minuten direkt loslegen können.

## Pflicht (alle)

1. **Cesium-ion-Account anlegen** (kostenlos, Community-Plan): https://ion.cesium.com/signup
   Ein Login mit GitHub oder Google geht auch.
2. Einmal https://sandcastle.cesium.com öffnen und auf **Run** klicken. Wenn sich der Globus dreht, funktioniert euer Browser. Chrome, Edge oder Firefox, aktuelle Version.
3. Die Datei [`data/campus_lod2.gml`](data/campus_lod2.gml) herunterladen: auf GitHub den Button **Download raw file** anklicken, ca. 10 MB.

## Optional (wer Schritt 5–6 selbst nachbauen möchte)

4. **Blender** (≥ 4.2) installieren: https://www.blender.org/download/
   Darin das Add-on **Bonsai** installieren: https://bonsaibim.org/download.html
5. **Python** (≥ 3.11) installieren, dann im Ordner `python/` ausführen:
   ```bash
   pip install -r requirements.txt
   ```
6. Das eigene Hausarbeitsmodell aus Revit als **IFC 4** exportieren und bereitlegen. Am Ende lassen wir es durch `ifc_roofs.py` laufen.
